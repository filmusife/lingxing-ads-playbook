# 功能差、产品阶段、竞品赢面

这三张卡和冷却规则对**任意品类**成立，不绑定研磨器。广告调整前必须先写完：**功能卡、阶段卡、竞品赢面**。没有这三张卡，禁止用“价格差不多”“ACOS 还行”决定加码或打竞品页。阶段和功能差决定**能不能打**；**今天能不能再动杠杆**还要看历史冷却（见 analysis-framework.md 第 9 节）。7 天内刚改过的 TOS/基础竞价，不能用 30 天滞后 CPC 再砍。

脚本 `analyze_ads_bundle.py` 的分桶只是弱先验（还带研磨器样例正则）。**手册必须按功能卡重分意图桶**，不要照抄 `buckets.tsv`。

## 1. 功能卡（先于一切竞价）

从属性表、后台 Listing、标题、五点、主图/A+ 抽取，禁止用广告出单词反推“我们有这个功能”。用户给了属性表，以属性表为准。

写四列，缺一不可：

| 列 | 写什么 | 广告含义 |
|---|---|---|
| 形态/架构 | 刀片 vs 锥刀、有线 vs 充电、滴滤 vs 意式、整机 vs 配件 | 不同形态 = IS NOT。形态错了，价格再低也打不赢对方页面的购物者 |
| 已验证功能 | 属性表/后台能证实的功能，带参数 | 才能做成功能精准仓 |
| 明确没有 | 竞品常见但我们做不到的 | 对应 query / ASIN 一律否或停，即使出过单 |
| 差异化 | 我们有、同形态竞品经常没有，或参数明显更好 | 这才是竞品广告的进攻点，不是价格本身 |

再标**页面可见性**：每个差异化是否出现在主图、标题、前两点？购物者从竞品页点过来，3 秒内看不懂，就当这个优势不存在。后台 Search Terms 里有、页面上没有的功能，**不能当赢点，也不要加码该功能词**。

三类功能不要混：

- **主粮功能**：决定小类节点的那个工作（磨咖啡豆、煮咖啡、吸尘）。对应核心大词，追求相关转化和 TOS 份额。
- **差异化功能**：静音、可拆碗、保温壶、双模式、大容量、定时、一键。出独立精准，中等 TOS。只打页面上看得见的。
- **标配功能**：不锈钢、电动、家用。人人都有，不能拿来证明“能赢竞品页”。

标题里出现的词 ≠ 小类主粮。刀片机标题写 espresso，只说明**相邻能转**，不是去抢锥刀/意式磨豆节点。咖啡机标题写 grinder，若没有内置磨豆，就是错品。

功能 → query 家族（写进手册，后续加码/否定都对照这张表）：

| 功能 | 可打的 query 家族 | 不能衍生去打的 |
|---|---|---|
| 已验证且页面可见 | 该功能的精确/词组、同义、场景词 | 把功能词扩到不同形态（静音刀片机去打静音锥刀） |
| 已验证但页面看不见 | 先不要加码；手册第 8 节写“Listing 要补”，广告侧维持观察，**不否** | 用广告去教育一个页面上没有的卖点 |
| 明确没有 | 否定 | 因为偶然出单就保留 |
| 标配 | 并入核心词，不单开功能仓 | 当成差异化去打竞品 |

### 1.1 强相关但广告数据差

这是否词前必须过的关，任意品类通用：

1. 这条搜索词要的**形态**，我们是不是？不是 → 才进入否定候选。
2. 要的**功能**我们有没有？没有 → 否。有但主图/标题/前两点看不见 → 不否，写 Listing 配合。
3. 数据差是不是**没打到点上**：基础竞价低于市场、TOS 份额接近 0、只打到 ROS、主图不像该意图、卖点埋在 A+ 里。这些都不是否定理由。
4. 用 `searchrank`（或曝光代理）判断是不是大词。大词差数据，优先加基础竞价/改位置/改页面，而不是否。
5. 脚本 `waste.txt` 只是花费警报。手册必须按功能卡重判；`*_do_not_negate` 的行禁止进否定列表。

反例（禁止写入手册）：“这个词相关，但 30 天 40 点击 0 单，否了吧。” 正确写法：先写它为什么 IS、页面哪一处支撑、searchrank/曝光如何，再在暂停 / 降基础竞价 / 抬基础竞价 / Listing 里选一个。

## 2. 竞品 / ASIN 赢面矩阵（禁止价格单因子）

商品投放、ASIN 搜索词、竞品品牌词，都用同一张矩阵。价格只是加分项，不是入场券。

对每个花费 ≥ $5 或有订单的竞品 ASIN / 竞品品牌，逐行填：

| 维度 | 怎么判 | 一票否决 / 加分 |
|---|---|---|
| 形态/架构 | 是否同一工作原理、同一使用方式 | **不同形态直接暂停**。刀片打锥刀、有线打充电、滴滤打意式、整机打配件，全停 |
| 对方凭什么被搜/被点 | 对方标题主图主打的那个功能，我们有没有 | **对方页的主卖点我们做不到 → 暂停**。购物者在那一页就是为了那个功能，便宜也骗不了转化 |
| 我们的可见差异化 | 可拆碗、静音、容量、双模式、保温壶等，对方没有且我们主图/标题看得见 | 有 → 可进攻（即使价格略高）。没有 → 不能靠“差不多”保留 |
| 价格带 | 成交价、券后价、划线价 | 同形态下更便宜是加分，不是通行证。更贵但可见功能明显更好，仍可打 |
| 评分 | 星级差 | 我方 <4.0 且对方 ≥4.3，很难赢，除非可见功能差极大且样本已证明 CVR |
| 评分数 | 我方/对方比值 | 对方评分数 ≥10 倍，且我方没有可见功能差 → 暂停。新品 18 评去打 2 万评的头部，几乎必亏 |
| 券/秒杀 | 是否临时折扣 | 只能解释当前 CVR，不能作为长期保留理由 |
| 配送/FBA | Prime、断货 | 对方缺货可短期打；我方可售低则不要打 |
| 主图信息量 | 点进对比后 3 秒能否看出差异 | 看不出 = 没有差异化 |
| 实测 CVR | 该 ASIN 投放 CVR vs 本品搜索广告 CVR | 明显低于搜索 CVR（例如不到搜索 CVR 的 60%）→ 暂停 |
| 数据缺失 | 拿不到对方评分数/价格 | 标 `DATA_MISSING`，用形态 + 我方 CVR 兜底；**仍禁止写“价格差不多所以留”** |

结论只允许三个，**先填矩阵再选动作**：

- **进攻**：同形态 +（可见功能优势 **或** 价格明显优势）+ 评分数不是碾压级劣势 + 投放 CVR 接近搜索水平。商品页溢价可留，TOS/ROS 必须为 0。
- **观察（默认先降基础竞价，不否）**：同形态、我方有可见差异化或互有胜负，但投放 CVR 低于搜索 CVR、点击不够，或价格接近却暂时打不过。动作是降基础竞价 / 降 PP / 降预算，给 7 天，不扩、不把 ASIN 加进否定投放。
- **暂停**：不同形态、对方主卖点我们没有、评分数碾压且无可见卖点、观察期后 CVR 仍明显差、或对方是纯品牌词收获页。这时才暂停或否定投放。

价格接近只说明「有资格进入矩阵」，既不能证明能赢，也不能证明该否。

竞品品牌词默认否。例外只有：搜索词是「竞品品牌 + 我们独有且页面可见的功能」（例如竞品没有保温壶，词是 `brand thermal carafe`），并且 30 天 CVR 接近搜索水平。即便如此也单独低预算，不进核心仓。

不要用“跟卖能出单”证明商品投放有价值。商品页跟卖几乎不喂搜索权重；出单只说明对比页没输光。权重目标下，ASIN 仓是收割/截流，不是养小类的手段。

## 3. 产品阶段卡

阶段决定：ACOS 容忍、活动数量、能不能打头部竞品、否定有多狠、要不要买 TOS、能不能按当前 CVR 扩量。

### 3.1 怎么判定

按下面信号综合，**不要只看评论数或只看上架天数**。Listing 字段优先：

- `open_date` / `open_date_time`：上架时间
- `first_order_time`：首单
- `reviews_num` / `stars`
- 7/14/30 天销量斜率（`average_seven_volume` vs `average_thirty_volume`）
- 广告单占比、小类 BSR、可售天数、库龄
- 价格状态：`landed_price` vs `listing_price` vs `regular_price` / `history_price`（券后价会把新品伪装成熟品）

| 阶段 | 典型信号（满足多条，不是单条绝对） |
|---|---|
| 新品冷启动 | 上架 <30 天，或评论 <50，或首单很近，或小类还在百名外且广告占比极高 |
| 新品爬坡 | 上架 30–90 天，评论大约 50–300，BSR 在进，7 天销量 ≥ 30 天日均 |
| 成熟收割 | 上架 >90 天，评论 300+，销量稳定，核心词已有转化样本 |
| 老品防御 | 评论高、小类已靠前（例如前 20），但广告单占比仍 >60%，自然位偏弱 |
| 衰退/高库存 | 可售天数 >90 且 7 天日均明显低于 30 天日均，库龄 91–180 升高 |
| 缺货保护 | 可售天数 <21，或可售很低且在途未入 |

促销期 CVR 变好 **不等于** 进入成熟期。券后价、秒杀、Coupon 要把阶段往“更早”判，不要往“更熟”判。

### 3.2 阶段 → 广告策略

**新品冷启动**

- 目标：相关 query 出单、攒评论、让核心词被索引。不是打爆头部、不是做低 ACOS。
- ACOS 容忍：明显高于成熟期。家电常见可放到 35–50%（有毛利目标用毛利）。核心相关词高 ACOS 先留；错品高 ACOS 立刻停。
- 架构极简：自动紧密 + 核心 exact（1–3 条家族）+ 品牌（有量再开）。**禁止一上来 15+ 个单关键词超高 TOS 活动。**
- 不要打评分数 10 倍以上的头部 ASIN，即使我们更便宜。社会证明不够，对比页必输。
- 不要打纯竞品品牌词。
- 否定极保守：只否硬 IS NOT（形态/做不到的功能）。相关词 0 单先留着给样本。
- TOS：中等。禁止低基础竞价叠 200%+ TOS。核心词要的是有效顶部竞价，不是溢价数字。
- 功能仓：只开页面已经写清的 1 个主差异化，不要把所有卖点同时铺精准。
- 发现广泛/自动宽泛/同类：能关先关，或极小预算。新品最怕错品点击打脏相关性。

**新品爬坡**

- 目标：核心大词稳定出单，开始用功能词养权重。
- 加功能精准仓（页面可见的差异化）。收割仓可以开，但赢家要迁走。
- 竞品 ASIN：只打同形态 + 可见功能能赢 + 评分数不是碾压的。
- 否定仍要 30 天样本；不要用 7 天 0 单否相关词。
- 可以开始管重复投放，但仍不要把结构做成 30 个活动。

**成熟收割**

- 目标：TACOS 下降、守住核心 query 转化、清错品。
- ACOS 锚：用健康核心词的 ACOS，不是组合平均数。
- 完整仓结构（核心/品牌/功能/收割/发现/自动紧密）。合并重复 exact。
- 竞品页按赢面矩阵进攻或停，不再“先开着看看”。
- 否定按 30 天严格清 IS NOT。
- 发现仓 TOS 压低；核心靠抬基础竞价保 TOS 份额。
- 若某核心词自然位已经稳定前 3，可降低该 exact 的 TOS，避免掏自己自然点击；把钱留给 TOS 份额仍低的相关大词。

**老品防御**

- 目标：用干净 query 把广告占比换回自然流量。广告单占比 70%+ 时，优先清洁而不是扩词。
- 核心大词订单和 CVR 必须稳住，否则小类会掉。
- 品牌仓保持高 TOS 防御。
- 错品、竞品品牌、做不到的功能，一律清。
- 不要再用新品式“广泛撒网买量”。

**衰退/高库存**

- 多砍错品和低 CVR 发现，少砍核心量。靠核心相关词消化库存，不靠大麻词/充电词/错形态词冲量。
- 可以保留高转化的相邻能转，但低预算、不冲 TOS。
- 不要新开发现仓。仓储费压力写进理由，但仍禁止用错品清库存。

**缺货保护**

- 停发现、停 ASIN、停 SBV/SD 扩量。只留最高 CVR 的核心/品牌，避免把最后库存卖给错品购物者（差评风险）。
- 可售上来之前不要加预算。

## 4. 促销、券、成交价

Listing 常见价格栈：`regular_price` / `list_price`（划线）→ `listing_price` → `landed_price`（券后/成交）→ `history_price`。

- 手册第 0 节必须写：当前成交价、是否有券/促销、促销大概让了多少。
- **促销中**：CVR 被抬高、ACOS 被美化。禁止按这个 CVR 去加发现、加 ASIN、把阶段判成熟。
- **促销结束**：先观察 3 天 CVR，再决定是否降核心基础竞价。不要促销一结束就按“ACOS 变差”砍核心大词。
- 历史低价、Coupon、秒杀都是临时赢面，赢面矩阵里单独标注“临时”，不写进长期保留理由。

有 FBA 费、佣金时，可以算**已知费用后的广告空间**，但没有 COGS 就不要假装算出保本 ACOS。用户给了毛利/目标 ACOS 就用用户的。

## 5. 阶段 × 活动架构

| 阶段 | 建议保留的仓 | 明确不要 |
|---|---|---|
| 冷启动 | 自动紧密、核心 exact、品牌 | 单词 250% TOS 矩阵、宽泛自动、同类、头部 ASIN、竞品品牌大仓 |
| 爬坡 | 上 + 功能 exact + 小收割 | 同一 query 开 3 个 exact 仓 |
| 成熟/防御 | 角色齐全，但每个角色 1 个主仓 | 34 个启用活动抢同一词 |
| 高库存 | 核心+品牌+能转的功能 | 新发现 |
| 缺货 | 核心+品牌 | 一切扩量 |

日预算远高于日耗 = 瓶颈在基础竞价/相关性/重复投放，不是加预算。  
日预算天天花尽且核心 TOS 份额还极低 = 先检查是否被垃圾仓抢走预算，再给核心仓加预算，不要给发现仓加钱。

动态竞价：

- `dynamic bidding - up and down` 会在位置溢价之上再抬价，发现仓和新品禁用。
- 优化期优先固定竞价（manual/fixed），否则你改的 TOS% 和实际 CPC 对不上。
- 已经在用动态提高的活动，手册里要写“实际 CPC 含动态加价，先改策略再谈基础竞价”。

## 6. 统计显著性（按本品 CVR，不按绝对点击）

不要用研磨器的 10% CVR 去否咖啡机的词。**期望 CVR = 本品搜索类广告（核心+功能，排除错品/ASIN）的中位 CVR。**

0 单相关词：

- 点击数 < `1 / 期望CVR`：样本不够，观察。
- 点击数 ≥ `3 / 期望CVR` 且 0 单：相关词先暂停 7 天；IS NOT 才否定。
- 例：期望 CVR 12% → 约 25 点击可暂停；期望 CVR 4% → 约 75 点击才够。咖啡机 20 点击 0 单不是定论。

出单但高 ACOS 的 IS 词：降基础竞价或降 TOS，不否定。否定会把相关流量也切断。

新品冷启动：把上述点击阈值再放宽一档，优先暂停而非否定。

新活动/新词：投放 <3 天且花费 < 3×该活动日预算，除非明显 IS NOT 或完全重复，否则不要暂停。

## 7. 功能差如何改具体动作

同一条搜索词，阶段和功能不同，动作完全不同。必须按这个顺序做决定：

1. 这条 query 要的形态，我们是不是？不是 → 否定/暂停。
2. 这条 query 要的功能，我们有没有、页面看得见吗？没有 → 否；有但看不见 → 不加码、不否，写 Listing 配合。
3. 现在是什么阶段？冷启动相关词即使 ACOS 高也先留样本；成熟期同样的词可以按阈值**暂停**，相关词仍不要直接否。
4. 若是竞品页：走赢面矩阵，不要跳到价格。矩阵=观察 → 降基础竞价；矩阵=暂停 → 才停。
5. 看 searchrank / 曝光代理：大词差数据先假设是竞价或位置问题。
6. 最后才看 ACOS、CPC、TOS 份额，决定加/降基础竞价还是改溢价。

反例（手册里禁止出现）：

- “对方 $24.99，我们 $25.19，价格接近，ASIN 保留”
- “这条充电词出过 2 单，先留着”
- “新品评论少，所以更要打头部竞品借流量”
- “组合 ACOS 已经 15%，可以扩广泛和同类”
- “促销期 CVR 18%，把发现仓 TOS 拉到 200%”
