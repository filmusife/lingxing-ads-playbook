# 冷却与配置快照（任意品类通用）

这套规则对**所有站点、所有品类、所有 ASIN** 生效：咖啡研磨器、咖啡机、吸尘器、配件、宠物、家电都走同一流程。禁止把研磨器样例正则、某个店铺的活动命名、或某一份旧手册当成别的产品的规则。

快照按 `profile_id + ASIN` 隔离。A 产品的 TOS 锁不会传到 B 产品。

## 1. 自变量 vs 因变量

| 类型 | 字段 | 能不能当“运营改过了” |
|---|---|---|
| 自变量（控制变量） | TOS / PP / ROS、日预算、启停、广告组默认基础竞价、关键词/投放基础竞价 | **能**。这是人敲进后台的值 |
| 因变量（结果） | 花费、CPC、曝光、点击、订单、CVR、ACOS、TOS 份额 | **不能**。流量结构、竞品出价、位置组合、大促都会让它们自己跳 |

Amazon Ads / 领星报表：指标是历史时序，属性永远是**查询当下的快照**。拉 9/18 的报表，看到的 `bid` / `placement_top` / `daily_budget` 仍是此刻值，不是 9/18 当天设置。

## 2. 每次分析必须做的事（不靠运营日记）

1. 用 Listing 的 ASIN / MSKU / local_sku 把活动圈进**本品**，不要把同店铺其他品类活动写进快照。
2. 拉取运营日志 `analytics_log_list_v2`（按本 ASIN）。
3. 从当前活动/广告组/关键词/投放抽出自变量，和上次快照做差分。
4. 把当前自变量写入：
   - 跨对话：`~/.codex/skills/lingxing-ads-playbook/state/{profile_id}_{ASIN}.json`
   - 本次：`analysis/config_snapshot.json`、`analysis/config_diff.tsv`、`analysis/cooldowns.tsv`
5. 手册第 0.5 节按冷却表填「维持 / 补做 / 新证据才可动」。

第一次跑没有旧快照是正常的：只写入，用运营日志锁最近 7 天改过的杠杆。第二次及以后才有 `TOS 160→90` 这种差分行。

## 3. 证据优先级

1. **配置快照差分**（自变量 old → new）
2. **领星运营日志**（改动日 + 对象；501 活动 / 502 广告组 / 504 投放 / 505 否定不锁溢价）
3. 用户口述
4. 本地上次手册（只对照「改成」数字）

`daily_breaks.tsv` 的花费/CPC 跳变只用来拆改后观察窗口，**不触发冷却锁**。

## 4. 锁什么、锁多久

| 差分到的字段 | 锁的杠杆 | 默认 |
|---|---|---|
| TOS / PP / ROS | 该活动对应位置溢价 | 7 天，最短 3 天 |
| 日预算 | 该活动日预算 | 7 天 |
| 启停 | 该活动启停（不要无证据重开） | 3 天观察 |
| 广告组默认基础竞价 | 该组默认基础竞价 | 7 天 |
| 某词/某投放基础竞价 | **只锁这条价**，不要把整仓 TOS 一起锁死 | 7 天 |

同一活动 TOS 7 天内禁止因为“30 天 CPC 仍是基础竞价 2–3 倍”连砍两次。冷却期内也不许把上次改动原路加回去，除非改后窗口核心大词日单腰斩。

## 5. 紧急例外（任意品类，不受冷却）

以**本产品功能卡**为准，不要套别的品类的 IS NOT：

- 功能卡里「明确没有」的形态/功能 → 否定或暂停
- 赢面矩阵 = 暂停的竞品 ASIN → 当天可停
- 同一 exact 多仓自相残杀、正在抢核心量
- 缺货 / IS NOT 活动还开着

例（只是例，手册必须按该 ASIN 功能卡重写）：刀片研磨器否 burr；有线吸尘器否 cordless；滴滤机否 espresso machine。

## 6. 圈定本品活动（防止串品类）

广告商品报表经常是空的。圈活动时按下面顺序，命中任一即属于本品：

1. 广告商品报表里 advertised ASIN = 本 ASIN
2. 活动名 / 组合名包含本 ASIN
3. 活动名包含 Listing 的 `msku` 或 `local_sku`（完整串，或长度 ≥ 6 且同时含字母和数字的片段）
4. 用户点名的广告组合 ID / 名称

不要：把同 Profile 下别的产品活动写进快照；不要因为「这个店铺只有一个组合」就把全店活动当成这一支 ASIN。

## 7. 重跑怎么出报告

- 快照或运营日志显示 7 天内改过自变量 → **delta/验收**。第 3 节冷却行「改成」= 维持。
- 冷却已满，且能拆出改后 ≥3 个完整日 → 只用改后窗口二次调整。
- 自变量没变、指标持续差 → 可以给新建议，但要写明“控制变量未改，这是新诊断”。

聊天先讲：锁哪些、补做哪些、今天不要动哪些位置。不要每天重写一套 TOS 矩阵。
